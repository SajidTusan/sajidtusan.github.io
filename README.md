# Sajid Hossain Portfolio

A modern, responsive personal portfolio for Sajid Hossain.

## Included
- CV-aligned profile, skills, education and experience
- Selected projects based on the latest CV
- Automatic public GitHub repository sync for `@SajidTusan`
- Dark/light theme
- Responsive mobile navigation
- Scroll reveal animations
- Accessible reduced-motion support
- Direct CV download
- GitHub, LinkedIn and email links

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Sync
The Projects section uses the public GitHub REST API in the visitor's browser. No API key is required for public repositories. If GitHub rate-limits the request, the direct GitHub link remains available.
